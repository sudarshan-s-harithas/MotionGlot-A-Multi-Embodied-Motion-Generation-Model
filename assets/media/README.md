# Project-page figures and demonstrations

These original assets are copied unchanged from the authors' [MotionGlot project page](https://ivl.cs.brown.edu/research/motionglot.html). They illustrate the published research demonstrations.

- `abstract.svg`: multi-embodied task overview.
- `overview.svg`: tokenization and instruction-training method.
- `rt2m/`: three robot generation GIFs.
- `ht2m/`: three human generation GIFs and three question-conditioned examples.
- `goal_reaching/`: three goal-reaching figures.
- `hmc/`: three human captioning GIFs.

`manifest.json` records every asset's source URL, byte count and SHA-256 hash. Figures and animations use repository-relative paths in the main README so that the media travels with the source release.
